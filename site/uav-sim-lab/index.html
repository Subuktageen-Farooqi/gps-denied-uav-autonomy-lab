    COMMAND-LINE WORKFLOW

    EXISTING TOOLS

    Export portable ONNX on your workstation

    python -m deployment.jetson_orin_nx.export_onnx --model path/to/best.pt --imgsz 640 --device cpu

    Build TensorRT on the Jetson Orin NX

    python -m deployment.jetson_orin_nx.build_tensorrt --model best.onnx --precision fp16

    Benchmark on the target device

    python -m deployment.jetson_orin_nx.benchmark --model artifacts/edge/jetson_orin_nx/model_fp16.engine --source validation.mp4

    Build TensorRT engines on the target device. INT8 needs representative calibration data and accuracy validation. Stored benchmark reports appear above after syncing them to lab compute.

    A CLEAR SEPARATION OF EVIDENCE

    FROM SENSING TO ACTION.

    Ground truth stays inside simulator generation, visualization, and evaluation. The autonomy stack consumes observations and estimated state.

    METRIC SIMULATION

    1. Seeded world & target motion
    2. Noisy relative observations
    3. Constant-velocity Kalman filter
    4. Confidence-aware autonomy FSM
    5. Predictive standoff goal
    6. Inflated-grid A* navigation
    7. Velocity controller & vehicle

    REAL PERCEPTION

    1. Uploaded camera image or clip
    2. Custom YOLO on NVIDIA L40S
    3. Bounding boxes & confidence
    4. Optional ByteTrack identities
    5. Calibrated camera intrinsics
    6. Azimuth & elevation
    7. Empirical reliability profiles

    Bounding-box pixels are never treated as metric world coordinates. This lab uses 2D kinematics and does not control real aircraft.
